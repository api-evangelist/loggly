# Loggly

> Loggly is a cloud-based log management and analytics service (part of SolarWinds) for aggregating, searching, and visualizing application, server, and infrastructure logs in real time. Ship logs over syslog or the HTTP/S event endpoint and query them through the apiv2 REST API (search, events, iterate, fields, stats). Authentication is bearer API tokens for retrieval and customer tokens for ingestion.

## APIs

- [Loggly Event Retrieval API](https://documentation.solarwinds.com/en/success_center/loggly/content/admin/api-retrieving-data.htm): apiv2 REST search/events/iterate/fields/stats. Base: https://[subdomain].loggly.com/apiv2
- [Loggly HTTP/S Event Endpoint](https://documentation.solarwinds.com/en/success_center/loggly/content/admin/http-endpoint.htm): event ingestion via customer token. Base: https://logs-01.loggly.com/inputs
